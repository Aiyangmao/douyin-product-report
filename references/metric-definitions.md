# 双期表格指标口径

参考表的品类顺序：主板、显卡、显示器、键盘、鼠标、耳机、特价、机箱、电源、散热、周边。品类汇总页分前期和后期两块，每个指标在两期使用相同公式。商品行的曝光、点击等人数按品类求和，只代表商品明细汇总，不代表店铺去重人数。

| 行指标 | 计算方式 / 来源 |
| --- | --- |
| 曝光 | 品类内`商品曝光人数`求和 |
| 点击人数 | 品类内`商品点击人数`求和 |
| 点击率 | 点击人数 ÷ 曝光 |
| 成交金额 | 品类内`成交金额`求和 |
| 成交订单数量 | 品类内`成交订单数`求和 |
| 成交订单占比 | 品类成交订单数量 ÷ 全店成交订单数，分母含路由器及未匹配商品 |
| 转化率 | 品类成交订单数量 ÷ 品类商品点击人数；这是参考表口径，不写成店铺去重转化率 |
| 品类流量占比 | 品类商品点击人数 ÷ 全店商品行点击人数之和 |
| 好评数 | 品类内`好评数`求和 |
| 好评率 | 好评数 ÷ 实际成交单数 |
| 退款金额 | 品类内匹配时间口径的退款金额求和 |
| 退款订单数 | 品类内匹配时间口径的退款订单数求和 |
| 退款率 | 退款订单数 ÷ 成交订单数量 |
| 实际成交单数 | 成交订单数量 − 退款订单数 |
| 实际成交单数环比 | 后期实际成交单数 ÷ 前期实际成交单数 − 1 |

整体店铺大盘含全部商品。可直接汇总：成交金额、退款金额、成交订单数、退款订单数。退款率 = 全店退款订单数 ÷ 全店成交订单数；实际金额 = 成交金额 − 退款金额。其余店铺去重或按次数的指标只有在收到同口径的店铺级来源后才填。若来源字段缺失，则依赖该字段的结果一并留空。

商品对比以商品编码在内部连接两期，但输出不显示编码。金额环比、点击人数环比、实际订单数环比分别用后期值 ÷ 前期值 − 1；前期为 0 时环比留空，不显示“新增 100%”。退款订单数可用时，实际订单数 = 成交订单数 − 退款订单数；不可用时可以只展示明确标成“成交订单数”的列。

所有比率使用未四舍五入的底层数计算，最后按参考表显示精度格式化。0 是真实零，空白表示无法从来源可靠计算，二者不能混同。
